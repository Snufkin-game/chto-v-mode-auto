RangeMedia — сайт и логотип
===========================

КАК РАЗМЕСТИТЬ САЙТ
1. Загрузите на хостинг всё содержимое этой папки целиком:
   index.html и папку brand/ (структуру не менять).
   Файл index.html должен лежать в корне сайта (обычно public_html или www).
2. Подходит любой обычный хостинг: Timeweb, Beget, REG.RU, Selectel,
   а также Netlify / Vercel / GitHub Pages. Сервер и база данных не нужны.
3. Привяжите домен rangemedia.ru к хостингу (в панели регистратора
   поменяйте DNS на те, что даст хостинг) и включите бесплатный SSL (https).
4. Проверьте сайт с телефона.

ЧТО ВНУТРИ
index.html                         — сайт целиком (стили и скрипты внутри файла)
brand/index.html                   — страница логотипа (брендбук), откроется по адресу /brand/
brand/rm-vertical-*.svg|png        — основной логотип: знак сверху, название снизу
brand/rm-horizontal-*.svg|png      — горизонтальный: для шапки, писем, бланков
brand/rm-horizontal-transparent-dark-ui.* — горизонтальный без фона, для тёмных макетов
brand/rm-avatar-*.svg|png          — аватары 1024×1024 для Telegram, VK, соцсетей
brand/rm-wordmark-dark.*           — только название RANGEMEDIA

dark   — на тёмном фоне (основная версия)
light  — на белом фоне (документы, печать)
cobalt — на синем фоне

SVG — для типографии, печати, дизайнеров (масштабируется без потерь).
PNG — для соцсетей, презентаций, мессенджеров.
